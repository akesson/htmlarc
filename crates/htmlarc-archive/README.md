# htmlarc-archive

Build and query `.htmlarc` archives of pre-parsed HTML. Includes streaming append, metadata, and memory-mapped readers. Source builds compile bundled zstd and need a C compiler.

Requires Rust 1.96 or later. Part of [htmlarc](https://github.com/akesson/htmlarc).
See the [project guide](https://github.com/akesson/htmlarc#readme) for installation,
examples, format compatibility, and limitations.

API reference: https://docs.rs/htmlarc-archive/
