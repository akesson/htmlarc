# htmlarc

Pack HTML into archives and query, list, probe, or diff documents from the command line.

Requires Rust 1.96 or later. Part of [htmlarc](https://github.com/akesson/htmlarc).
See the [project guide](https://github.com/akesson/htmlarc#readme) for installation,
examples, format compatibility, and limitations.

```sh
cargo install htmlarc --locked
htmlarc pack ./pages -o pages.htmlarc
htmlarc list pages.htmlarc
```
