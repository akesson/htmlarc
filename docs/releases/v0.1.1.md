htmlarc 0.1.1 adds a Python wheel for Windows on ARM64. `pip install htmlarc`
on native ARM64 CPython no longer falls back to building from source, which
needed Rust and a C compiler. The wheel is tested on CPython 3.11 and 3.14,
the oldest and newest Windows ARM64 releases available.

There are no library, CLI, or archive format changes from 0.1.0. The crates are
republished only to keep versions aligned across registries.

```sh
pip install htmlarc
cargo install htmlarc --locked
```
