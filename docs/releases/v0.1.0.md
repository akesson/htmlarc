htmlarc 0.1.0 is the first public release: store HTML documents as pre-parsed DOMs
and query them with CSS selectors without parsing the HTML again.

- Python package for building, appending, and querying archives, parallel scans,
  typed metadata, and Arrow export. Requires CPython 3.10 or later.
- Rust DOM and archive libraries, plus the `htmlarc` CLI on crates.io.
- Unix downloads containing `htmlarc` and the ZIM/WARC/directory converter.

Install after publication:

```sh
pip install htmlarc
cargo install htmlarc --locked
```

Read the [Python guide](https://github.com/akesson/htmlarc/blob/v0.1.0/crates/htmlarc-py/README.md)
and [project documentation](https://github.com/akesson/htmlarc/tree/v0.1.0).
Binary downloads cover Linux and macOS on x86-64 and ARM64; Windows x86-64 is
supported through Python wheels. Source builds require Rust 1.96+ and a C compiler.

This release uses archive format v12. Older development archives require their
original reader to export, or source HTML to rebuild. Keep original inputs;
format/API compatibility may change in future minor versions before 1.0. Use
trusted archives and one writer at a time. The parser uses HTML5 tokenization
with pragmatic tree recovery, not the complete browser tree-building algorithm.
